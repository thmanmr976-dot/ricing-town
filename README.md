# Ricing Town · Desktop Studio

الإصدار 0.6 يضيف تصميمًا متعدد الشاشات: ملفات تعريف للمخارج والدقة والمقياس والموضع، معاينة منفصلة لكل شاشة، واستهداف العناصر لشاشة محددة أو لجميع الشاشات. يصدر Hyprland قواعد الشاشات، ويقيد Quickshell وWaybar بالمخارج المختارة.

الإصدار 0.5 يضيف **Visual Logic**: يمكن لكل عنصر تغيير النص واللون والشفافية والحركة وفق البطارية أو المعالج أو الذاكرة أو الشبكة أو الموسيقى أو حالة الشحن، من خلال حقول مرئية ودون أوامر.

الإصدار 0.4 يضيف فاحص توافق وتصدير **Hybrid**: تُرسل مكونات الشريط الأصلية إلى Waybar، بينما ترسم Quickshell العناصر الحرة ومكونات Widget Neighborhood. استخدم **Export package → Inspect compatibility** قبل التنزيل.

يستورد Asset Manager مجلدات الأيقونات والمؤشرات المحلية بحدود واضحة، ويسجل SHA-256 والترخيص والمصدر. تُضمّن الحزم داخل `assets/theme-packs` وتظل خطوة تثبيتها صريحة وتحت تحكم المستخدم.

محرر ويب محلي لتصميم سطح مكتب Hyprland. التشغيل: `npm start` ثم افتح http://127.0.0.1:5173 . يحتاج Node.js حديثًا، دون تثبيت حزم. أوقف الخادم بـ Ctrl+C.

## الوضع الحي والمساعد المحلي

أصبح للمحرر وضعان صريحان: **Demo** للمحاكاة الآمنة، و**Live** لبيانات الجهاز والأفعال المؤكدة. لا ينتقل المحرر إلى بيانات تجريبية إذا انقطع المساعد؛ يعرض disconnected أو stale ويُبقي القيم غير المتاحة واضحة.

1. شغّل المحرر: `npm start`.
2. في طرفية ثانية شغّل المساعد بصلاحيات المستخدم العادي: `npm run helper`.
3. اضغط **Pair helper** وأدخل الرمز المكوّن من ستة أرقام الظاهر في الطرفية.
4. اختر Live. يعرض الصوت الحقيقي، مساحة العمل النشطة، الشبكة، البطارية وMPRIS حسب الأدوات المتاحة.

المساعد مربوط حصريًا بـ `127.0.0.1:5174`. يتحقق من Origin وHost، يستخدم رمز جلسة لا يدخل ملف المشروع أو الرابط، يحد الطلبات والمهل والأحجام، ولا يقبل أوامر shell أو مسارات تنفيذ أو scripts. تشغيل التطبيقات محصور في سجل ثابت ويستخدم executable وargument array. إجراءات الطاقة تحتاج تأكيدًا منفصلًا ولم تُنفذ في الاختبارات. راجع [توثيق البروتوكول](docs/helper-protocol.md) وخدمة systemd الاختيارية في `packaging/ricing-town-helper.service`؛ المشروع لا يثبتها تلقائيًا.

صيغة المشروع الحالية v5. ملفات v1–v4، ومنها Amethyst والتصاميم المحفوظة سابقًا، تهاجر عند الفتح مع حفظ أسماء العناصر والأصول والإجراءات القديمة. يضيف v5 اختصارات وقواعد Hyprland المرئية وتعريفات Widget Neighborhood والحركات المحدودة إلى نفس الملف.

## ما أصبح متاحًا
- **Widget Neighborhood** لإنشاء Custom Widget ونصوص وأشكال، وربطها بالوقت والتاريخ والمعالج والذاكرة والبطارية والموسيقى والشبكة، مع قوالب جاهزة وثلاثة أسطح مكتب مختلفة: Neon Orbit وPaper Calm وAurora Grid.
- حركات Pulse وFloat وRotate وGlow وSlide وFade مع مدة وتأخير ومنحنى وتكرار، ومع احترام `prefers-reduced-motion` في المتصفح.
- محرر مرئي لاختصارات Hyprland الآمنة وقواعد النوافذ ومساحات العمل، دون قبول أوامر shell عشوائية.
- خلفية صورة PNG/JPEG/WebP حتى 8 MB، لون أو تدرج، تموضع وتغطية الصورة، تعديل نص سطح المكتب أو إخفاؤه.
- شفافية الخلفية، تمويه، ظل، حدود، خطوط النظام أو رفع TTF/OTF حتى 4 MB، وأيقونات نصية وقوالب ألوان.
- Bar وDock وClock وWorkspaces وVolume وNetwork وBluetooth وBattery وNotifications وApplications وMusic وCPU وMemory وPower.
- Brightness وTemperature وDisk وUptime، مع بيانات حقيقية في المساعد المحلي وQuickshell عندما تكون الأدوات والملفات النظامية متاحة.
- قائمة تطبيقات وإجراءات جاهزة؛ Music للتحكم بالمشغل وSettings للصوت. تمييز الاختصارات غير المرتبطة. أوامر المشاريع القديمة محفوظة لكن لا تُنفذ كأوامر عشوائية.
- تحديد متعدد بـ Shift، محاذاة إلى حدود الحاوية، توزيع ثلاثة عناصر أو أكثر، التقاط للحواف والمراكز، أدلة أثناء السحب، تثبيت العناصر داخل الشاشة والحاويات، أحجام شاشة ومراسي متجاوبة.
- Preview يخفي لوحات المحرر؛ Hide all controls يخفي أدوات المعاينة أيضًا. Escape يرجع للتحرير. بيانات المعاينة تجريبية، باستثناء الوقت والتقويم المحليين.
- حفظ تلقائي في IndexedDB مع نسخة سابقة، وترحيل الحفظ القديم من localStorage، واستعادة المشروع السابق عند الاستيراد. سجل تراجع/إعادة حتى 40 حالة في الجلسة. Save .rce نسخة محمولة تشمل الصورة والخطوط.

زر Open Amethyst example يفتح التصميم الأصلي دون تعديل. زر Open Amethyst Studio يفتح نسخة إضافية من التصميم فيها كل المكونات وإجراءات الموسيقى والإعدادات مرتبطة. كلاهما يحتفظ بالمشروع السابق في نسخة الاستعادة. النسخة الأصلية محفوظة كذلك في Hyprland-Amethyst.original.rce.

## التصدير والتطبيق
Export package يوفّر حزم المكونات المنفصلة، بينما **Download Full Rice** يجمع إعدادات Hyprland 0.55+ Lua وملف توافق 0.54، وQuickshell أو Waybar، والثيمات الاختيارية لـ Kitty/Foot وRofi/Wofi وSwayNC وHyprlock وGTK، ونسخة project.rce والأصول. استخدم `sh install.sh --dry-run` أولًا؛ `--apply` ينسخ إلى `~/.config/ricing-town` مع نسخة احتياطية ولا يعدّل ملف Hyprland الرئيسي. `restore.sh` يعيد آخر نسخة احتياطية.

فك الحزمة وشغّل `sh start.sh` داخل مجلدها بعد توفير Quickshell وPython وQtQuick Controls/Effects. خدمات المكونات اختيارية: WirePlumber للصوت، playerctl/MPRIS للموسيقى، NetworkManager وBlueZ وswaync لوظائفها. القيمة غير المتاحة تظهر بوضوح. لا يغيّر التصدير إعداداتك تلقائيًا. لإيقاف التجربة استخدم Ctrl+C؛ احذف سطر التشغيل التلقائي الذي أضفته فقط إن استخدمته. احتفظ بإعداداتك الأصلية وخدمة الخلفية الحالية.

## القيود الفعلية
- التصدير يدعم Quickshell حاليًا؛ لا يوجد مُصدّر Waybar أو تثبيت تلقائي.
- التمويه في معاينة الويب فقط. الظلال قد تقص عند حدود النافذة الأصلية. التدرج يصدر أفقيًا أو عموديًا، والتوزيع space-between للاختصارات يصدر كمجموعة وسطية ذات مسافات ثابتة.
- الشبكة والبلوتوث والإشعارات تعرض الحالة وتفتح التطبيقات الأصلية للإدارة. لا تمثل اللوحات الأصلية نسخة مطابقة للوحات المتصفح.
- التطبيقات قائمة محددة، وليست اكتشافًا تلقائيًا لكل تطبيقات الجهاز. الأيقونات رموز نصية وتعتمد على الخط.
- ربط مفاتيح سطح المكتب القديم يبقى محفوظًا ولا يثبت تلقائيًا. كل الشاشات تعرض التصميم نفسه، ولا يحجز الشريط مساحة للنوافذ تلقائيًا.
- bridge.py يبقى مساعد حزمة Quickshell. أما `helper.mjs` فهو مساعد المحرر المستقل، ببروتوكول موثق واقتران ومصادقة وقائمة إجراءات ثابتة. يستخدم polling محدودًا حاليًا؛ اشتراكات الأحداث المتخصصة وتعدد أجهزة الصوت والبطاريات والمشغلات ما زالت مرحلة لاحقة.
- الحفظ التلقائي خاص بمتصفح وعنوان الموقع، وليس بديلًا عن تنزيل ملف .rce. سجل التراجع لا يستمر بعد إعادة التحميل.

## الاختبارات
`npm test` و`python3 tests/bridge_test.py`: 21 اختبار JavaScript و4 اختبارات للمساعد المحلي. تغطي التوافق مع Amethyst، الأصول، الهندسة، المحاذاة، الاستعادة، التراجع والعزل ومنع الأوامر غير المدعومة.

تم اختبار الواجهة في Chrome ومتصفح التطبيق: تعديل الخصائص، المكونات، استعادة الحفظ بعد التحديث، تفاعل الموسيقى والصوت، المعاينة النظيفة، رفع خلفية وخط، تنزيل .rce وإعادة فتحه، وتنزيل ZIP والتحقق من سلامة جميع ملفاته ووجود الصورة والخط. احتاج اختبار الرفع في Chrome إذن file URLs للإضافة؛ اكتمل عبر متصفح التطبيق.

حُمّلت QML داخل Quickshell 0.3.1 في اختبار offscreen باستبدال نوافذ PanelWindow مؤقتًا بـ FloatingWindow في نسخة الاختبار فقط. هذا يتحقق من التحميل والمكونات، ولا يثبت المطابقة البصرية أو جميع تكاملات Wayland على جلسة Hyprland فعلية. لم نطبق الحزمة على سطح مكتب المستخدم ولم نختبر أوامر الطاقة الفعلية.
